# 💻 Universal Android Debloater (UAD-ng) – Gefahrloses PC-Debloating

**Universal Android Debloater - Next Generation (UAD-ng)** ist das leistungsfähige PC-Pendant zu mobilen Tools wie *Canta*. Es ermöglicht dir, Xiaomi/Poco-Bloatware und Telemetrie-Pakete übersichtlich über einen Computer (Windows, macOS, Linux) per Grafikoberfläche zu entfernen.

## 📦 Download & Bezugsquellen

* **GitHub Repository:** [Universal Android Debloater (UAD-ng) auf GitHub](https://github.com/Universal-Debloater-Alliance/universal-android-debloater-next-generation) (Letzte Releases für Windows, macOS & Linux)

## 🌟 Hauptfunktionen

* **Community-Datenbank:** Jedes gefundene App-Paket wird automatisch mit einer Risikobewertung versehen (*Recommended*, *Advanced*, *Expert*, *Unsafe*).
* **Sicheres Entfernen:** System-Apps werden im **User-Space (User 0)** deinstalliert. Das System bleibt stabil, und gelöschte Apps können jederzeit mit einem Klick wiederhergestellt werden.
* **OEM-Spezifische Listen:** Enthält vorgefertigte Filterlisten speziell für Xiaomi / Poco (MIUI & HyperOS).
* **Multi-Package Auswahl:** Ermöglicht das saubere Entfernen ganzer Bloatware-Kategorien in wenigen Sekunden.

## 🛠️ Einrichtung & Nutzung

1. Aktiviere auf deinem Smartphone das **USB-Debugging** unter `Einstellungen ➔ Entwickleroptionen`.
2. Verbinde dein Gerät per USB-Kabel mit dem PC.
3. Lade **UAD-ng** von GitHub herunter und starte die Anwendung.
4. Wähle im Dropdown-Menü das Profil **Recommended** aus, um gefahrlos vorgeschlagene Bloatware und Telemetrie-Pakete auszuwählen.
5. Klicke auf **Selection entfernen**. *(Tipp: Nutze Canta auf dem Smartphone für spätere Feinjustierungen im Alltag).*
