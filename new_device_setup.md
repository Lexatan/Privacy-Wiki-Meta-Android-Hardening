# New Poco/Xiaomi Device Setup Checklist

## Step 1: Initial Setup
1. Turn on the device and select your language.
2. Connect to Wi-Fi (preferably a secure network).
3. Sign in to your Google account (consider using a new account for privacy).

## Step 2: Basic Settings
1. Navigate to **Settings** > **Privacy**.
2. Disable features like location history, app activity, and personalized ads.

## Step 3: Anti-Tracking Settings
1. Go to **Settings** > **Privacy** > **Permission manager**.
2. Review app permissions and revoke any unnecessary access.
3. Enable **Allow only while using the app** for location permissions.

## Step 4: Install Privacy-Focused Apps
1. Uninstall default apps that track data (if possible).
2. Install apps like DuckDuckGo, Signal, or Telegram for private communication.
3. Use a VPN service for enhanced privacy.

## Step 5: Regular Maintenance
1. Regularly check app permissions and privacy settings.
2. Keep your device updated to the latest Android version.
3. Consider using custom ROMs known for privacy (advanced users only).
